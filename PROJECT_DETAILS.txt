1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
Project Name: Student Attendance & Timetable Management System
Platform: Cross-Platform (Android, iOS, Web, Windows/macOS/Linux Desktop)
Primary Language: Dart (Flutter Frontend) & JavaScript (Node.js Backend)
Target Audience: Academic Institutions, Faculty Members, Students, and Administrators

Managing manual attendance registers and paper-based timetables is time-consuming 
and prone to data loss or manipulation. This application digitizes hourly classroom 
attendance tracking for faculty while empowering administrators with centralized 
schedule management. It features AI-powered OCR timetable scanning using Google 
Gemini AI, GPS-verified campus geofencing for attendance logging, and dual offline/cloud 
data persistence.


2. KEY FEATURES & FUNCTIONALITIES
--------------------------------------------------------------------------------
[A] GPS-Verified Attendance Logging:
  - Ensures faculty can only log hourly classroom attendance when physically inside 
    the campus perimeter using device GPS coordinates.
  - Captures headcount of students present, faculty name, section, department, date, 
    and timestamp.
  - Works offline first using SQLite, with seamless cloud backend syncing.

[B] AI-Powered Timetable Scanning (OCR + Gemini AI):
  - Ingests image photos of physical timetable sheets from camera or gallery.
  - Extracts raw text using Google ML Kit Text Recognition on-device.
  - Sends extracted text to Google Gemini 1.5 Pro/Flash to parse unstructured 
    schedules into clean, structured JSON timetable data.
  - Saves analyzed timetables persistently for quick view across departments.

[C] Role-Based Access Control & Portals:
  - Admin Portal: Protected by passkey authentication to restrict schedule modification.
  - Admin Features: Create, view, update, delete schedules by semester (Sem 1 - Sem 8), 
    manage department timetables, purge database entries, view live records.
  - Faculty/User Portal: View daily & weekly class schedules, record attendance, 
    upload department timetables.

[D] Multi-Department & Multi-Semester Management:
  - Support for multiple academic departments (CSE, ECE, ME, CE, ISE, AI/ML, etc.).
  - Categorized timetable management per semester (Semesters 1 through 8).

[E] Dual Storage & Hybrid Sync:
  - Local Database: SQLite (`sqflite` & `sqflite_common_ffi`) for fast client performance.
  - Cloud Database: Node.js REST API integrated with MongoDB for remote cloud access.

5. CONFIGURATION & ENVIRONMENT SETUP
--------------------------------------------------------------------------------
[1] GOOGLE GEMINI AI SETUP:
    - Step 1: Obtain an API key from Google AI Studio (https://aistudio.google.com/).
    - Step 2: Set the key in `assets/.env`:
        GEMINI_API_KEY=your_actual_api_key_here
    - Step 3: Or configure directly in `lib/config/api_config.dart`.
    - Purpose: Converts OCR text extracted from timetable photos into structured JSON.

[2] CAMPUS GPS GEOFENCING SETUP:
    - Located in `lib/screens/record_attendance_screen.dart`:
        static const double COLLEGE_LATITUDE = 12.9716;
        static const double COLLEGE_LONGITUDE = 77.5946;
        static const double ALLOWED_RADIUS_METERS = 1000.0; // 1km radius
    - Update latitude and longitude to your institution's center point.

[3] BACKEND SERVER ENVIRONMENT (`backend/.env`):
    - File location: `backend/.env`
        MONGODB_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/?appName=Cluster0
        PORT=3002


6. REST API ENDPOINTS (NODE.JS BACKEND)
--------------------------------------------------------------------------------
Base URL: http://localhost:3002/api

SCHEDULE ENDPOINTS:
  - GET    /api/schedules/semester/:semester  -> Fetch all schedules for a specific semester
  - POST   /api/schedules                     -> Create a new schedule entry
  - PUT    /api/schedules/:id                 -> Update an existing schedule by ID
  - DELETE /api/schedules/:id                 -> Delete a specific schedule entry by ID
  - DELETE /api/schedules/semester/:semester  -> Delete all schedules for a given semester

TIMETABLE PHOTO ENDPOINTS:
  - GET    /api/timetable-photos              -> Fetch all uploaded timetable photos
  - GET    /api/timetable-photos/:department/:semester -> Filter timetable photos
  - POST   /api/timetable-photos              -> Upload new timetable photo record
  - PUT    /api/timetable-photos/:id          -> Update timetable photo record
  - DELETE /api/timetable-photos/:id          -> Delete a timetable photo record

SYSTEM HEALTH:
  - GET    /health                            -> Returns server status ("OK") & timestamp


7. HOW TO RUN THE PROJECT
--------------------------------------------------------------------------------
STEP 1: Run the Backend REST API Server
  1. Open terminal and navigate to backend directory:
     cd backend
  2. Install dependencies:
     npm install
  3. Start the server:
     npm start   (or 'npm run dev' for nodemon live-reload)
  4. Server starts listening on http://localhost:3002

STEP 2: Run the Flutter Mobile / Web App
  1. Open a new terminal in the root project directory (`demo/`).
  2. Get dependencies:
     flutter pub get
  3. Launch the app on your preferred target (emulator, web, or desktop):
     flutter run
